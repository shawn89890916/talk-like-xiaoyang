## 怎么看这些数

- 高频只说明它在当前候选语料里常见，不能单独证明它是固定口头禅。
- “口水词”按预设词条统计，可能在不同语境里承担不同作用；例如“就”“啊”“所以”不一定是填充词。
- 亲疏关系、单一高频会话、引用或转发会影响比例；原始统计不等于对每种场合的判断。
- 明细 JSON 只保留聚合数，不包含联系人、会话 ID 或原句。
