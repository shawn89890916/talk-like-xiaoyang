# 怎么校准“像不像”

这里的 10 个案例全部是合成情境，不含真实聊天摘录。当前没有完成本人盲评，没有所谓模仿准确率。

先用相同事实生成普通版本和参考档案的版本，隐藏版本来源，再请本人判断。聊天、文章、正式内容分开评，不用总分掩盖场景差异。

每次关注五件事：

1. **事实与意图**：有没有增加、删掉或改写重要事实、立场、条件与承诺。
2. **展开顺序**：本人是否会先说这件事，理由和下一步放得是否合适。
3. **场景合适**：是否符合当前对象、用途、礼貌和信息完整性要求。
4. **表达自然**：句长、措辞、承接是否自然，有没有刻意塞口头禅。
5. **实际可用**：本人愿不愿意直接使用，需要改哪一句。

本人指出的问题应保留为有场景的修正记录。单次觉得“挺像”只能说明该次样本，不代表所有任务都已验证。

`analysis/validate_repository.py` 只验证数据、文件与隐私边界，不评估模仿质量。程序通过不能替代本人反馈。
