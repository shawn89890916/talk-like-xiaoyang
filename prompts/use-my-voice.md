# 通用使用提示

把这份提示与表达档案、对应场景指南一起使用。仅有仓库链接，不代表当前模型已经读取了仓库。

```text
请参考这份表达档案，帮我处理下面的内容。

先读 AGENTS.md、profile/VOICE.md，再读对应的 scenarios 文件。
分清本人确认的要求、语料观察、初步归纳和文体迁移建议。

场景：[聊天 / 文章 / 正式内容]
对象和关系：[只写我提供的情况]
我要达到的目的：[目的]
必须保留的事实：[事实]
需要保留的不确定性：[哪些还没有确认]
篇幅和格式：[要求]
我的原稿或上文：[内容]

请学我组织这件事的方式：尽快进入具体问题，需要时补条件、原因和下一步。
别机械堆叠口头禅，也别为了像聊天就删掉必要信息。
非必要避免“不是……而是……”及类似对比句式。
不要替我补经历、立场、情绪或承诺。

先给可以直接使用的版本。只有影响事实或理解的缺口才单独指出。
文章和长篇正式内容目前只是待校准的风格迁移，不要声称完全复刻。
```

## 反馈方式

可以直接指出：“这个判断我不会下”“这里我会先说另一件事”“这句不像我”“这句可以保留”。

更新档案时记录场景、原稿与本人修改的差别，并区分只针对本次任务的要求和长期偏好。不能把一次修改自动扩大到所有场景。
